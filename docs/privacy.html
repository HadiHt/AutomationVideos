Automation Videos

Privacy Policy

Last updated: June 7, 2026

1. Overview

Automation Videos is a desktop-local application for generating short-form vertical videos from user-provided scripts and, if the user chooses, publishing those videos to TikTok using TikTok's authorized developer interfaces.

2. Information We Process

Depending on how the application is used, Automation Videos may process:

  • User-provided script text.
  • Generated local assets such as audio, images, captions, and rendered MP4 files.
  • TikTok authorization data, such as access tokens and related account metadata, after the user chooses to connect a TikTok account.
  • Publish settings selected by the user, such as title text and privacy options.

3. How Information Is Used

Information is used to:

  • Generate local video content from the user's script.
  • Store generated files and job state on the user's device.
  • Connect to TikTok only when the user explicitly authorizes the application.
  • Submit a video to TikTok only when the user explicitly confirms a publish action.

4. Local Storage

Automation Videos is designed to run locally. Generated assets, render outputs, and local application state are stored on the user's machine, subject to the user's own device configuration and file retention choices.

5. TikTok Data

If the user connects a TikTok account, Automation Videos may store TikTok access credentials and related account metadata locally in order to support authorized publishing workflows. TikTok data is used only for the requested integration behavior and only after user authorization.

6. Sharing

Automation Videos does not intentionally share user-generated content or TikTok account data with third parties except where needed to fulfill the user's requested workflow, such as sending a video to TikTok after explicit authorization and publish confirmation.

7. Security

Reasonable efforts should be made to protect local credentials and generated files. Because the application runs on the user's own computer, the security of stored data also depends on the security of the user's device and environment.

8. User Choices

Users may choose whether to:

  • Enter script content into the application.
  • Connect a TikTok account.
  • Publish generated content to TikTok.
  • Delete local files generated by the application.
