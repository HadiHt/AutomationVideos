Automation Videos

Generate vertical videos locally, then publish them to TikTok with explicit user authorization.

Automation Videos is a desktop-local workflow for turning a script into a TikTok-style MP4 using local AI tools, then letting the account owner review and publish the result through TikTok's official authorization flow.

What it does

  • Generates voiceover locally from a written script.
  • Creates background images through a local ComfyUI installation.
  • Renders vertical videos with captions and audio on the user's own computer.
  • Lets the user review the final video before publishing.
  • Uses TikTok authorization so the user chooses whether to connect and publish.

How it works

  1. The user enters a script into the local app.
  2. The app generates voice, scenes, captions, and a final MP4 on the user's machine.
  3. The user reviews the output and selects TikTok publish settings.
  4. The user explicitly authorizes TikTok access and confirms publishing.

Data handling summary

Automation Videos is designed to run locally. Generated scripts, media assets, and output videos are stored on the user's device. TikTok account access is only used after the user authorizes the application and chooses to publish content.
